# 특징 계산 및 탐색 규칙

## 데이터 범위

- 정상: DAT 좌표 정답 마스크의 009, 019 이미지(세포 20개)
- Abnormal: DAT 좌표 정답 마스크의 016, 017 이미지(세포 9개)
- 특징은 `masks/{norm,abnorm}/reference/`의 정답 마스크에서 계산합니다. 예측 마스크는 특징 임계값을 정하는 데 사용하지 않습니다.
- 원본 픽셀 크기 보정값이 제공되지 않아 면적 단위는 px², 길이는 px입니다. 실제 물리 단위로 환산하지 않았습니다.

## 정의와 구현

`extract_and_evaluate_masks.py`에서 이진 마스크를 읽어 아래처럼 계산합니다.

| 특징 | 계산 | 단위 |
|---|---|---|
| 핵 면적 | 핵 마스크의 전경 픽셀 수 | px² (픽셀 개수) |
| 핵 둘레 | OpenCV `findContours(RETR_EXTERNAL, CHAIN_APPROX_NONE)`의 외곽 윤곽에 `arcLength` 적용 | px |
| 원형도 | `4π × 핵 전경 픽셀 수 / 둘레²` | 무차원 |
| 종횡비 | 핵 외곽의 axis-aligned bounding box 긴 변 / 짧은 변 | 무차원 |
| 세포질 면적 | 정답 세포질 마스크의 전경 픽셀 수 | px² (픽셀 개수) |
| N/C | 핵 면적 / 세포질 면적 | 무차원 |

경계 기반 원형도는 픽셀화와 윤곽 방식의 영향을 받습니다. 이 작업에서는 위 윤곽 검색 설정을 고정했습니다. 종횡비는 타원 피팅이 아닌 bounding box 방식을 사용했습니다. 특징 CSV에는 `measurement_units`와 계산 불가 사유가 포함됩니다. 필요한 정답 마스크가 없거나, 마스크 크기가 맞지 않거나, 핵·세포 대응이 의심되는 경우 계산을 보류합니다.

## 정답 대비 예측 분할 평가

원본 이미지 좌표계에서 정답과 예측 마스크의 union Dice 및 IoU를 계산합니다. 객체별 수는 Hungarian assignment로 1:1 매칭한 뒤 IoU가 0.50 이상인 경우만 매칭으로 인정합니다. 매칭되지 않은 정답은 누락, 매칭되지 않은 예측은 오검출로 셉니다. 이 평가는 예측 성능을 요약하지만 수동 경계 검토를 대체하지 않습니다.

세포질 Dice/IoU도 기록했지만, 경계가 타당한지 김승연을 포함한 팀의 육안 검토는 아직 완료되지 않았습니다. `mask_quality_metrics.csv`와 `mask_overlays/`를 함께 확인하고, 검토 결과를 별도로 기록해야 합니다.

## 탐색 규칙

현재 저장된 예시 규칙은 다음과 같습니다.

```text
핵 면적 > 1800 px² AND N/C > 0.15 → 검토 필요
그 외 계산 가능한 행 → 규칙 미충족
필요 마스크·대응이 불명확해 특징 계산 불가 → 분석 불가
```


## 네 이미지 한정 파라미터 조정

정상 009·019, abnormal 016·017의 정답 마스크로 전통적 영상처리 임계값을 직접 비교해 해당 이미지 ID의 고정 override를 코드에 넣었습니다. 정상 코드는 핵 후보 최소 면적 300 px² 및 거리 변환 peak prominence 10.0, abnormal 코드는 이미지별 국소 명암차와 세포색 지지율을 사용합니다. 신경망·머신러닝 학습이나 추론은 사용하지 않았습니다. 이 비교 이미지들에 맞춘 조정이므로 다른 사진에 성능이 이어진다는 보장은 없고, 이 네 장에서의 결과를 독립적인 일반화 성능으로 해석해서는 안 됩니다.

이 네 장에서 조정 전·후 평균 union IoU는 핵 0.301→0.388, 세포 0.549→0.623, 세포질 0.442→0.509였습니다. 이미지별 수치는 `reports/tuning_comparison.csv`와 `reports/mask_quality_metrics.csv`를 확인하세요. 후보 수 감소만으로 정확도가 높아졌다고 판단하지 않고 핵·세포·세포질 마스크의 점수와 누락·오검출을 같이 봅니다.

객체 단위 누락·오검출 수는 IoU 0.50 이상만 매칭한 결과입니다. 조정 후에도 abnormal 016에서는 핵 4개 중 1개, abnormal 017에서는 5개 중 0개만 이 기준을 통과했습니다. 따라서 union IoU 개선에도 불구하고 핵 객체 분할은 아직 충분히 정확하지 않습니다.

## K-means / PSNR 별도 비교

`kmeans_psnr_experiment.py`는 요청에 따라 OpenCV K-means 색 군집화와 PSNR을 시험합니다. K-means는 비지도 군집화이므로 머신러닝으로 분류될 수 있습니다. 이 실험은 기존 normal/abnormal 분할 코드에 통합하지 않았습니다. K-means는 긴 변 900 px로 축소한 이미지에서 LAB, HSV, LAB+XY와 K=3~6을 비교합니다. PSNR은 8-bit 이진 마스크 기준이며, 축소된 좌표계에서 계산합니다.

네 이미지에서 핵 분할은 K-means 최고 IoU가 기존 코드보다 낮았습니다. abnormal 세포·세포질에서도 정답으로 군집 조합을 고른 경우조차 기존보다 낮았습니다. Normal 세포·세포질은 몇몇 색 공간/군집에서 개선됐지만, 최선의 군집 선택이 이미지마다 달랐습니다. 정답을 보고 최고 조합을 고른 값은 낙관적 상한이며 배포 가능한 규칙이 아닙니다. PSNR도 배경 픽셀이 많으면 높게 나올 수 있어 주 지표로 쓰지 않습니다. 전체 결과는 `reports/kmeans_experiment/summary.md`와 CSV에 있습니다.
